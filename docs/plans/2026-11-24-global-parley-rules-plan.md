# Глобальный PARLEY.md

Один пользовательский файл `PARLEY.md` в активной домашней папке Parley (обычно `~/.parley`) задаёт общие инструкции для всех проектов. Хост перечитывает его при каждом запуске процесса агента.

1. В `packages/core/src/work/parley-md.ts` переиспользовать чтение и обработку проектного файла для глобального блока. В `launch.ts` и `session-layer.ts` добавить его перед проектными правилами в общий слой запуска. Критерий — штатные провайдеры получают оба блока при запуске, а возобновление читает актуальную версию. Отсутствующий файл не требует настройки. Ошибки чтения и обрезку до 32 КиБ показывают отдельные уведомления в протоколе и Desktop.
2. В `packages/host/src/assistant/assistant-service.ts` и `job-executor.ts` передать тот же глобальный блок системным промптом Claude Code или файлом инструкций Codex. Критерий — обычный ход помощника и фоновое поручение получают правила из того же дома Parley.
3. Описать путь, момент чтения и требования к пользовательским шаблонам провайдеров в `README.md`. Проверить регрессии в тестах общего слоя запуска, помощника и фоновых поручений.
