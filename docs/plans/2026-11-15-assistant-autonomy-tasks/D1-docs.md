# D1 — CHANGELOG и пометки в прежних спеках

- **Исполнитель:** junior. **Зависимости:** A8, W4, W5.
- **Сначала прочитать:** `00-common.md`; Спека §4 и §9; План §4, D1; `CHANGELOG.md` — последние три записи, чтобы
  повторить их вид.

## Цель

Изменение описано для пользователя, а прежние спеки ссылаются на новую там, где она их меняет.

## Шаги

1. **`CHANGELOG.md`**, раздел невыпущенных изменений (в том виде, в каком его ведут последние записи), по-английски:
   - автономный режим помощника: переключатель в Settings → Assistant, выключен по умолчанию; действия с острова
     исполняются без карточки; Telegram и телефон по-прежнему спрашивают;
   - помощник сам сообщает ответ сессии, которой дал работу;
   - значок режима, ход плана и «Stop» на острове; список последних действий в настройках;
   - изменение для всех: строка `VOICE_PROMPT` о действиях.
2. **`docs/specs/2026-10-28-assistant-hands-design.md`** — в начало, после строки с датой, один абзац: какие решения
   меняет спека `2026-11-15-assistant-autonomous-mode-design.md` (её §4: решение 2 и §9 «только карточкой и
   кликом» — при включённом режиме; §5.4 — на этапе 2).
3. **`docs/specs/2026-11-04-voice-assistant-modules-design.md`** — такой же абзац: §3 (`VOICE_PROMPT`), §4 (Request без
   делегации), §6 (статусы), §10 («запись — только через карточки»).

Больше в прежних спеках ничего не менять.

## Проверка

- `git diff --stat` показывает три файла;
- в каждой из двух спек изменён только добавленный абзац;
- запись в CHANGELOG не обещает того, чего на ветке нет: сверь с `git log --oneline origin/master..HEAD`.

## Готово, когда

Один коммит `docs: …`; в отчёте — текст записи CHANGELOG целиком.
