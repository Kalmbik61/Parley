# W5 — недавние сессии во входе job

- **Исполнитель:** junior. **Зависимости:** W3.
- **Сначала прочитать:** `00-common.md`; Спека §6.4, §6.5 (RW-17); План §3, W5; отчёт W1 (`recent()`).

## Цель

Голосовое поручение «скажи ему, что…» уходит нужной сессии без поиска: вход job называет последние сессии, которым
помощник давал работу.

## Шаги

1. `packages/host/src/assistant/job-context.ts`: `createJobPrompt` получает необязательный источник
   `recentSessions(): Array<{ name: string; work: string }>` и, если список не пуст, добавляет ко входу job блок:

   ```
   Agents you recently gave work to (most recent first):
   - <name> in work "<work>"
   ```

   Не больше трёх строк. Идентификаторов в блоке нет: модель находит сессию по имени обычными инструментами.
2. `packages/host/src/host.ts` (сборка `createJobPrompt`, около `:1017`): источник — `recent()` модуля слежения из W1.
3. Блок добавляется только обычным job (происхождение `island`, `mobile`), не пересказчику.

## Тесты

`job-context.test.ts`:

- список пуст — входа блок не меняет (существующие ожидания не правятся);
- две сессии — две строки в порядке «новая первой», с именем и работой;
- пять сессий — три строки;
- в блоке нет `s-`, `session:`, `work:`;
- вход job происхождения `system` блока не содержит.

## Не делать

- Не менять остальной вход job и правила `link_request`.
