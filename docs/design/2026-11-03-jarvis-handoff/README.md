## О файлах дизайна
Файлы в `design/` — **HTML-референсы**. Они показывают, как экран выглядит и как себя ведёт, но это не продакшн-код. Задача — **воссоздать их в React Native** по паттернам кодовой базы: Animated с native driver и react-native-svg (бриф, раздел 5).

- Открывать `design/*.dc.html` в браузере. Нужен интернет: React, Motion и шрифт Golos Text грузятся с CDN. `support.js` — рантайм этих файлов, в приложение он не переносится.
- У каждого кадра `id` совпадает с номером экрана (`#R05`, `#R10·1`), подпись экрана лежит в `data-screen-label`. Все стили инлайновые, поэтому точные значения можно прочитать прямо из разметки.
- `design/components-reference.js` — генератор кадров шагов 2–3. В нём компактно и точно описаны все общие компоненты (шапки, поле ввода, карточки, кнопки, REC) и SVG-пути иконок. Это не код для приложения, а самый быстрый способ взять цифры.
- Статус-бар, Dynamic Island, home indicator, скругление кадра 48 px и тень вокруг кадра — обвязка макета. Это системные элементы, рисовать их не нужно.

## Точность

## Поведение
- **Поле ввода доступно при любом результате.** Прежние результаты не исчезают: карточка остаётся в ленте у своего сообщения.
- **Подпись в шапке обязательна.** Состояние никогда не передаётся только цветом или движением. Подпись называет действие («проверяю расписание», «собираю карточку», «не удалось собрать карточку»).
- **Ход работы.** Пока идёт работа, показывается строка со спиннером и текущим шагом. Тап раскрывает список, текущий шаг в нём отмечен кольцом (R24, R03). После завершения они сворачиваются в «✓ N шагов», тап снова раскрывает.
- **Done и карточка.**
  - Done (конец текста) сразу разблокирует ввод: «Стоп» исчезает, поле переходит в «Пусто» или «Набор».
  - Карточка приходит после done: готовится → готова или ошибка. «Собираю карточку» видно только в её рамке, шапку и сферу это не меняет.
  - Ошибку снимает «Повторить», текст ответа при этом не пропадает.
  - Свежесть — отдельный признак.
- **Подтверждение:** ожидает → выполнено (R06·2, запись в журнале) / истекло (R06·1, только «Запросить заново») / отменено. Пока ждёт решения, поле ввода доступно: можно ответить словами.
- **Нет связи:** лента читается, черновик сохраняется, отправка выключена и объяснено почему. Молчаливой очереди нет.
- **Темы:** группы в Истории строятся по времени последнего обсуждения. Фрагмент ведёт в ту же ленту с подсветкой 1,5 с. «Продолжить в разговоре» и «Спросить в разговоре» ничего не отправляют. Плашка контекста действует только на следующее отправленное сообщение.
- **Голос, встреча, «Стоп» и покупки** — целевой UX следующих этапов. На кадрах они не выдаются за уже работающие функции.
- **REC:** отдельный постоянный индикатор. Виден на всех экранах, не прячется за «нет связи» и «ошибкой». Мини-сфера запись не показывает.

### Движение
- **Один фазовый осциллятор на сферу.** Каждый кадр `φ += f·dt`. Значение = `from + (to − from)·(1 − cos 2πφ)/2`, то есть sine in-out с периодом 1/f. Дрейф пятен идёт с периодами T×1,7 / 2,1 / 1,4.
- **Смена состояния:** частота и амплитуда меняются твином 600 мс ease-in-out (ждёт решения — 300 мс, ошибка — 180 мс). **Фаза не сбрасывается**, поэтому скорость дыхания меняется без рывка.
- **Цвет:** кроссфейд двух градиентных слоёв — новый слой проявляется поверх за 300 мс (ошибка — 180 мс, reduced motion — не больше 100 мс), старый снимается в конце.
- **Индикаторы** (кольцо, дуга, сектор, точки, значки): появляются за 200 мс ease-out (кольцо подтверждения — за 150), исчезают за 150 мс ease-in.
- **Громкость:** атака 50 мс, спад 180 мс. Кольцо: scale 0,96 + 0,26·L, opacity 0,25 + 0,6·L. Голос: пульс ядра 0,62 с до +5 %·L (у мини — не больше 2 %), ореол +0,28·L. В прототипе громкость имитируется, в приложении брать реальный уровень микрофона и TTS.
- **Reduced motion:** все циклы выключены. Статичные признаки:
  - слушает — кольцо 1,12;
  - думает — слой повёрнут на 150°, тёплый c2;
  - работает — дуга на −30°;
  - формирует — сектор на 135°, точки 0,9 / 0,6 / 0,3;
  - говорит — значок динамика, scale 1,02;
  - ждёт решения — кольцо с разрывом;
  - ошибка — «!»;
  - нет связи — серая, opacity 0,72.

### Правила выбора
- «Занятые» состояния — думает, работает, формирует. Вход в занятое из незанятого — через 150 мс. Переход между занятыми — не раньше чем через 400 мс после показа текущего.
- Правдивые события меняют состояние **сразу**: запись остановлена, связь пропала, нужно подтверждение, начал играть голос. Выход из занятого — тоже сразу.
- Приоритет без аудио: нет связи → ошибка операции → блокирующее подтверждение → подготовка карточки → работа инструмента → размышление → покой.
- Подготовка карточки после done сферу не меняет (правка R04): «Собираю карточку» — только в рамке карточки. Вариант «собираю карточку» с точками на листе R21 в разговоре не используется.

### Перенос в React Native
- scale / opacity / rotate / translate и кроссфейд — `Animated` с native driver. Дуги и кольца — react-native-svg. Градиенты — SVG `RadialGradient` / `LinearGradient` со `stopOpacity`.
- Плавная смена частоты и реакция на звук требуют покадрового осциллятора. Кандидаты — Reanimated 3.17 / 3.18 (`useFrameCallback`); выбор зафиксировать после проверки сборки. 3.19 с RN 0.77 не совместим.
