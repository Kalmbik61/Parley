# План реализации: комната разговора агентов

Дата: 2026-09-23. Основание: `2026-09-23-agent-room-design.md`.

> **Как гонять.** Пять кусков строго по порядку: три из них трогают `app.tsx`.
> Агентам `model: 'sonnet'`; после каждого куска — прогон `pnpm build`,
> `pnpm test`, `pnpm lint`, линзы и разбор дифа человеком, потом коммит.
> Каждый коммит зелёный сам по себе.

**Правила проверки** — те же, что в плане темы: линзы исходят из того, что
дефект есть; у линз разные имена временных файлов; линза вида рендерит кадр на
`ink-testing-library`, а не читает диф; границы — инвариантом по диапазону;
`tsc` в tui не смотрит тесты.

## Кусок 1. Имена и вид ленты

Чистые функции, UI ещё не подключён: картинка не меняется.

**Файлы:** `packages/core/src/work/thread.ts` (`sessionTag`),
`packages/core/src/model-badge.ts` (`modelName`), `packages/core/src/index.ts`,
тесты рядом; новые `packages/tui/src/room-view.ts` (`participantTag`,
`roomView`) и `room-view.test.ts`.

**Приёмка:**

- `sessionTag('s-01') === 'S01'`, `s-12` → `S12`; чужая форма — как есть;
- `modelName`: `claude-opus-5-5` → `Opus 5.5`, `claude-fable-5-1` → `Fable 5.1`,
  `claude-sonnet-5` → `Sonnet 5`, `gpt-5.2-codex` → `Codex`, `<synthetic>` и
  `null` → `null`; незнакомое — как есть, обрезка до двенадцати знаков;
  `modelBadge` не меняется;
- `participantTag`: известная — `S03 (Codex)`, модель неизвестна — подпись
  провайдера, удалённая — `S02 (удалена)`, чужой id — как есть;
- `roomView` берёт **все** письма работы; заголовок письма —
  `ЧЧ:ММ  S03 (Codex) → S01 (Opus 5.5)` и вид словом (`· вопрос`,
  `· решение`); тело с новой строки без отступа; пустая строка между письмами;
  `▤` перед временем непрочитанного; **ни одна строка не `dim` из-за
  прочитанности**; первая строка — участники в порядке сессий; блок решений с
  новыми подписями; прокрутка и `below`/`total` как в `thread-view.ts`;
- тест на данных вида `w-0010`: у корневой сессии ярлык в двести знаков — ни
  одна строка ленты его не содержит.

## Кусок 2. Сайдбар: номер и строка комнаты

**Файлы:** `components/sidebar.tsx`, `use-selection.ts`, `use-actions.ts`
(ходьба `j`/`k` по целям), `app.tsx` (передать сайдбару число писем и
непрочитанных); тесты сайдбара и выбора.

**Приёмка:**

- строка сессии: `● S03 <ярлык> <состояние>`; общая ширина строки прежняя —
  инвариантом по набору ширин; пол `MIN_LABEL` и слово состояния целы;
- строка `▤ комната` последней в блоке сессий, справа число писем или `▤N`;
  без писем строки нет;
- цель `kind: 'room'`: клик, `j`/`k` и стрелки доходят до неё и уходят с неё;
  выбор комнаты не отключает и не закрывает сессию;
- существующие тесты сайдбара правятся только там, где в строку сессии
  добавился номер, и это видно в дифе построчно.

## Кусок 3. Комната на месте панели

**Файлы:** новые `use-room.ts` (прокрутка и кэш вида — из `use-thread.ts`) и
`components/room.tsx`; `app.tsx` (при выбранной комнате панель рисует
комнату), `use-actions.ts` (`t` выбирает комнату и возвращает назад, клавиши
прокрутки), `use-prefix-input.ts` (пока выбрана комната, ввод гостю не
уходит, колесо над панелью листает ленту), `components/status-bar.tsx`
(`t комната` в подсказке перед настройками).

**Приёмка:**

- выбрана комната — в зоне панели лента во всю ширину и высоту, в рамке панели,
  шапка `комната · N писем` с `▤N` и `↓N`;
- ни один байт ввода не уходит гостю, пока выбрана комната — проверка на
  подставном PTY;
- `↑`/`↓`/`j`/`k`, `PgUp`/`PgDn`, `End`/`G` и колесо листают; новое письмо не
  сбивает позицию, ушедшую вверх;
- `ctrl+q t` из сессии открывает комнату, повторно — возвращает в ту же
  сессию; в работе без писем — событие «писем в работе пока нет»;
- тема и монохром: роли `fg.default`, `fg.muted`, `status.unseen`, `bg.panel`;
  при уровне 1 кадр без заливки.
