# План реализации: окно харнаса — комнаты, решения, облик Organic

**Цель:** воссоздать в `packages/desktop` hi-fi редизайн из handoff и дописать нужное в
`core`, `protocol` и `host`. Что входит:
- облик Organic;
- комната с 1..N агентами и ведущим;
- решение, которое ждёт человека;
- упоминания, черновики и перетаскивание в сайдбаре.

**Спека:** `docs/specs/2026-09-29-desktop-rooms-organic-design.md`. Её раздел «Статус и
решения» сильнее текста handoff ниже в ней. Исходник handoff — прототип, снимки и
`TASKS.md` — лежит в `docs/design/2026-09-29-rooms-organic/`.

**Стек:** Electron 44, React 18, TS strict ESM, Tailwind 4, примитивы shadcn/ui в
`renderer/ui/`, zustand 5, vitest + jsdom, Playwright `_electron`. Протокол — zod в
`packages/protocol`.

## Global Constraints

- **Тексты окна** — только английские, из `packages/desktop/src/shared/strings.ts`. Страж —
  `english-ui`. Русские строки на снимках — пример данных.
- **Рамка.** Юридическая рамка README и чек-лист 15.1 спеки Orca-UI:
  - учётные данные агентов не читать;
  - в `~/.claude` и `~/.claude.json` не писать;
  - скрытых запусков нет;
  - за агента на диалоги не отвечать;
  - лимиты подписки не показывать и к API не ходить.
- **Протокол** только добавляется. `PROTOCOL_VERSION` остаётся 1, новые методы — в
  `hello.methods`. Окно прячет функцию, если метода нет.
- **Сеть.** Окно не ходит в сеть. Шрифты, значки и прочее — локально, с лицензиями в
  `NOTICE`.
- **Контраст.** Вторичный текст — не ниже 4.5:1 в обеих темах, это держит
  `styles/tokens.test.ts`. Признак состояния — не ниже 3:1.
- **Иконки lucide** — везде `strokeWidth` 2.75.
- **Визуал** — где размер прототипа расходится со спекой Orca-UI, берётся прототип.
  Поведение, которого прототип не показывает, берётся из спек окна и Orca-UI.
- **Тесты и E2E:**
  - настоящий `claude` в тестах не запускается, только стаб `HARNAS_CLAUDE_BIN`
    (`e2e/stub-echo-agent.mjs`);
  - E2E работают в своих временных каталогах;
  - буфер обмена, уведомления macOS, Finder и браузер человека не трогаются.
- **Коммиты и репозиторий:**
  - коммиты по-русски, последняя строка — `Co-Authored-By`;
  - стейджинг явными путями;
  - `.omc/` и `.superpowers/` не коммитить, НИКОГДА не делать `git stash`;
  - неотслеживаемый `packages/desktop/prototype/` не трогать.

## Review Focus

1. **Длинные значения.** Длинное имя работы, комнаты, сессии, пути и ветки не выталкивает
   элементы за край: строки сайдбара, лента участников, диалоги. Проверять в 800×500.
2. **Обе темы.** Каждый новый вид проверяется в светлой и тёмной теме. Контраст текста — по
   токенам, а не на глаз.
3. **Старые карты.** Карта v2 без `lead` и `proposal` читается. Сессия в нескольких комнатах
   в старой карте не ломает сайдбар (решение 4 спеки).
4. **Гонка решения.** Устаревший `proposalId` отвечает `conflict`. Повторное нажатие
   `Accept` не дублирует сообщения. Пока решение ждёт, новое письмо всем цикл не
   перезапускает.
5. **Упоминания.** `@` в середине слова и в email не открывает меню. Чип удаляется целиком.
   Вставка — только текст. Без упоминаний `to: []`, то есть всем.
