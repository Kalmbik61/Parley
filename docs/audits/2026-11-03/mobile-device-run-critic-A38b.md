# Ревью критика: A38b (`82e69018`, меню сессии в приложении)

Дата: 2026-11-03. Критик: независимый субагент Opus ведущего s-174, только чтение. Предмет: `82e69018`, влит как
`6df92dd0` в `feat/mobile-device-run`. Прогон: `session-menu.test.ts` 11, `remote-client` `live` + `rpc-timeout` 25,
`tsc` mobile — зелёные. Текст перенесён ведущим без изменений по существу.

**Вердикт: блокеров 0, major 1, minor 5.**

## Major

**M1. При повторе после потери связи `requestId` не сохраняется.**
- **Где:** `mobile/src/feed/SwitchSheet.tsx:23,43-48`, `app/session/[ref].tsx:512-515`.
- **Почему:** `requestId` живёт, пока лист смонтирован, а `onDone` закрывает лист при любом итоге, в том числе при
  `lost`. Текущего провайдера лист не показывает.
- **Сценарий.** Claude → Codex. Связь рвётся, а хост замену применил. Человек снова открывает лист: Codex уже
  текущий, и хост убрал его из целей. По умолчанию выбран Gemini, Continue, и уходит вторая замена: только что
  запущенный агент останавливается.
- **Исправление.** При `lost` лист не закрывается: цель и `carry` заморожены, «We couldn't confirm it» и Try again с
  тем же `requestId`. Новый id выдаётся только после определённого ответа. Текущий провайдер виден в листе. Тест.

## Minor

- **m1. Причина недоступности показывается сырым кодом.**
  - `switch-model.ts:47-49` выводит `needs` как есть, а хост шлёт коды `cli | key | sign-in | error`.
  - Демо и тест расходятся с хостом: в них готовые фразы, текущий провайдер стоит среди целей, у Codex
    `transcript: true`.
  - Проценты не округлены.
- **m2.** `keeps.leads` и `keeps.owns` — это id комнат, а не люди (`switch-model.ts:38`). Нужны названия комнат из
  снимка.
- **m3.** `not_connected` показывается тостом «not connected» (`actions.ts:165`). Нужен свой итог «Not sent —
  reconnecting».
- **m4.** Пустой список целей даёт пустую плашку (`SwitchSheet.tsx:73,121`). Нужна строка «No other provider on your
  Mac».
- **m5.** Тесты: `lost` у `switchAgent` и `switchOptions` в `remote-client`; жизнь `requestId` — в модели, с тестом.
