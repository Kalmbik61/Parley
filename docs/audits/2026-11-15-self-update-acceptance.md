   ```bash
   pnpm --filter @parley/desktop dist --dir -c.extraMetadata.version=0.34.0
   ```

   Версия подменяется только в собранном `package.json`, дерево не меняется. Ожидается `packages/desktop/dist/mac-arm64/Parley.app` (на Intel — `mac/Parley.app`). Проверить версию: `defaults read packages/desktop/dist/mac-arm64/Parley.app/Contents/Info CFBundleShortVersionString` → `0.34.0`.
