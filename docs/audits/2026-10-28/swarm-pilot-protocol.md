## Правило подсчёта (до прогонов)

- По каждому вопросу судья ставит покрытие: 1 — ответ полный и верный, 0.5 — частичный или с существенным пропуском, 0 — нет ответа или неверный. **Покрытие задачи** = сумма / 8.
- **Ложные утверждения** — число утверждений, опровергнутых судьёй (неверный `path:line`, неверное поведение). **Доля ошибок** = ложные / все проверенные утверждения.
- **Время** — от старта до записи ответа (по шапкам, сверка с картой сессий).
- **Расход** — токены по сессиям и моделям из журналов сессий (вход, выход, кэш-чтение, кэш-запись); деньги — только по прайсу провайдера с датой; где данных нет — «неизвестно», не ноль.
- **Выигрыш роя** = покрытие R ≥ покрытия S, доля ошибок R не выше S + 5 п.п., и время R меньше времени S. Дешевле ли рой — отдельный вывод, не условие выигрыша (замер wfgate: фан-аут покупает время).
- Один прогон — не доказательство. Поднимать одновременность выше 4 по спеке можно только после двух выигрышей.
