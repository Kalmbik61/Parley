# Установка и первые шаги в Parley

## Скачайте приложение для своего Mac

Parley работает на macOS 13 Ventura и новее. В меню Apple → «Об этом Mac» найдите строку «Чип» или «Процессор» и выберите подходящий образ из последнего выпуска. [Выпуски Parley](https://github.com/Kalmbik61/Parley/releases/latest)

| Mac | Образ |
| --- | --- |
| Apple Silicon (M1 и новее) | [parley-macos-arm64.dmg](https://github.com/Kalmbik61/Parley/releases/latest/download/parley-macos-arm64.dmg) |
| Intel | [parley-macos-x64.dmg](https://github.com/Kalmbik61/Parley/releases/latest/download/parley-macos-x64.dmg) |

Откройте образ и перетащите Parley в папку «Программы». Сборка для Intel пока не проверена на Mac с процессором Intel.

## Разрешите первый запуск

У Parley пока нет подписи Apple Developer ID. Если macOS блокирует запуск загруженного приложения, попробуйте открыть Parley, затем в системных настройках откройте «Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

Если Parley находится в папке «Программы», метку карантина можно снять в «Терминале».

```bash
xattr -dr com.apple.quarantine /Applications/Parley.app
```

Затем снова откройте Parley.

## Подключите агента

Установите хотя бы один CLI и войдите в его аккаунт. Parley находит команды `claude` и `codex` через `PATH` вашей оболочки входа.

- Claude Code и Codex можно запускать через встроенный терминал. Для вкладки чата нужны Claude Code 2.1.286 или новее либо Codex 0.160.0 или новее.
- Для автопроверки разрешений нужен Codex 0.162.0 или новее. В более ранних версиях запросы появятся в терминале.
- Для GLM нужны Claude Code 2.1.287 или новее, подписка GLM Coding Plan и ключ Z.ai. Введите ключ в карточке провайдера. Parley хранит его на этом Mac.
- Для работы с Git нужна команда `git` в `PATH`. Для предварительного просмотра конфликтов слияния используйте Git 2.38 или новее.

Установленному приложению отдельный Node.js не требуется.

## Выберите язык и создайте первую работу

1. Откройте настройки сочетанием ⌘,. В поле «Язык интерфейса» выберите «Русский» и перезапустите Parley.
2. Нажмите ⌘N и выберите папку проекта.
3. Нажмите ⌘T, чтобы создать сессию одного агента или комнату для нескольких агентов.
4. Напишите задачу в комнате и дождитесь решения ведущего.

Сочетание ⌘J открывает палитру команд. В поле роли и списке сценариев встроенные варианты отображаются на выбранном языке. Для запуска из командной строки используйте постоянный идентификатор, например `builtin:executor` для роли «Исполнитель».

## Справка по командам

Команда `parley-core --help` выводит справку на выбранном языке в stderr. Результаты команд с данными по-прежнему передаются в stdout как JSON.

```bash
parley-core --help
parley-core work list --all
parley-core work map --work w-01 --cwd "$PWD"
```

Подставьте в команду `work map` идентификатор работы из `work list`. Из собранного репозитория можно вызвать `node packages/core/dist/cli.js --help`. [Сборка из исходников](../README.md#build-from-source)

## Обновления

Parley проверяет выпуски на GitHub и показывает уведомление. Для установки новой версии завершите работу Parley сочетанием ⌘Q, скачайте новый образ и замените приложение в папке «Программы». Для новой сборки может потребоваться повторное разрешение запуска. Работы и настройки хранятся отдельно от приложения. [Выпуски Parley](https://github.com/Kalmbik61/Parley/releases/latest)
