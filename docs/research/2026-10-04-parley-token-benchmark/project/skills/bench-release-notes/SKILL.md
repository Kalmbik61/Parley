# bench-release-notes

Create `docs/RELEASE-<version>.md` with exactly these headings, in this order:

1. `# Release <version>`
2. `## Highlights` with at most three bullets
3. `## Upgrade` with one line that starts with `Run: `
4. `## Contact` with the line `Questions: team@bench.invalid`
