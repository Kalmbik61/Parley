# Code Mode: базовый корпус (T1a)

Замер «до» для Code Mode на закреплённой базе `f7978af8156cfb426016f999fb6d36798adf7d73`: объявления инструментов Parley и пять настоящих цепочек вызовов. Источник чисел — спека `docs/specs/2026-11-07-code-mode-design.md`, §2 и приложение A.3; задача — T1a плана `docs/plans/2026-11-07-code-mode-plan.md`. Стенд — `tools/parley-token-benchmark.ts`, команда `code-mode-baseline`.

## Файлы

- `baseline-manifest.json` — замороженные числа приложения A.3: хеши исходников базы, 13 строк корпуса схем, разбор SDK, точные строки `tools/list` по stdio, провенанс трёх транскриптов (имя файла, длина и sha256 префикса, число строк) и пять цепочек (строки, блоки, id вызовов, байты, токены и sha256 полезной нагрузки). Ни текста сообщений, ни локальных путей.
- `synthetic-transcript.jsonl` — синтетический транскрипт для тестов стенда (выдуманные id и тексты). Это отдельный корпус, не обезличенная копия настоящего: числа манифеста он не воспроизводит.

## Как воспроизвести

```sh
# Токенизатор — вне репозитория, в отдельном временном каталоге:
mkdir -p "$TOKDIR" && cd "$TOKDIR" && npm init -y && npm install --save-exact --no-audit --no-fund js-tiktoken@1.0.21
# В чекауте базы (после pnpm install --frozen-lockfile):
pnpm exec tsx tools/parley-token-benchmark.ts code-mode-baseline --tokenizer-dir "$TOKDIR"
(cd tools && pnpm exec vitest run parley-token-benchmark.test.ts)
```

Команда собирает исходники `--target` (по умолчанию этот чекаут) через esbuild из зависимостей `tsx`, считает корпус в исходном порядке, после разбора MCP SDK и на проводе stdio, затем ищет транскрипты по имени файла в `--root` (по умолчанию `~/.claude/projects`) и сверяет всё с манифестом. Итог по частям: `ok` — совпало, `FAIL` — расхождение (код выхода 1), `N/A` — вход недоступен: нет токенизатора (байты и хеши всё равно сверяются), нет транскрипта. Недоступное числами не заполняется. Запись прогона с локальными путями пишется только под `.parley/` (по умолчанию `.parley/benchmark/code-mode-baseline.json`).

Токенизатор проверяется до подсчёта: версия 1.0.21, sha256 `dist/index.cjs` и словаря `o200k_base`. Другая версия или другие байты — отказ.

## Что это не измеряет

- Токены `o200k_base` — счёт фиксированным токенизатором по корпусу, а не usage провайдера: ни кеша, ни контекста, ни биллинга. В учёт `sumUsage` стенда они не попадают.
- Пять цепочек — подобранные исторические примеры, а не выборка трафика; ревизия сервера в момент тех вызовов неизвестна.
- Числа описывают только закреплённую базу. Новая поверхность инструментов — отдельный прогон с отдельным манифестом.
