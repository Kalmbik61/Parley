# Проверка обновлённого preview · 28 сентября 2026

Проверяется только `packages/desktop/prototype/rooms`. Production Electron/core/host не менялись и не запускались в этой работе. Агентов и команды запускают только демонстрационные переходы в localStorage.

## Автоматические проверки

Команды из корня проекта:

```sh
node --test packages/desktop/prototype/rooms/src/model.test.mjs packages/desktop/prototype/rooms/src/task-creation.test.mjs packages/desktop/prototype/rooms/src/mentions.test.mjs packages/desktop/prototype/rooms/src/MentionEditor.test.mjs
pnpm --dir packages/desktop exec vite build --config prototype/rooms/vite.config.mjs
```

ESLint из каталога preview: `pnpm exec eslint --config eslint.config.mjs src`.

- 18 тестов: 5 переходов решений/плана, 5 единого создания/запуска задачи, 3 разбора упоминаний, 5 DOM-проверок редактора.
- Создание одного участника сохраняет provider/model/effort/worktree/context.
- Добавление второго сохраняет ID беседы и существующую историю.
- Существующие участники не перезапускаются, чужой workspace не принимается, дубли отсекаются.
- Launch prepared изменяет только pending-участников; существующие процессы и история остаются прежними.
- Парсер mention распознаёт точные известные коды без учёта регистра, сохраняет окружающий текст и исключает email/чужие коды; маршрутизация не дублирует адресатов.
- DOM-проверки: вставка кнопкой после потери фокуса, выбор из меню, последовательный ввод с пробелами, вставка в середине и Backspace, plain-text paste. Редактор сохраняет нативные текстовые узлы во время ввода, нормализация mention не заменяет их на каждом input.
- `vite build` и локальный ESLint проверены. Предупреждение Vite о `use client` в Lucide не мешает сборке SPA.
