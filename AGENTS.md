# Project rules

## Language

Everything that leaves the working tree is written in English:

- commit messages, subject and body;
- pull request titles and descriptions, review comments and replies on GitHub;
- `CHANGELOG.md` entries and release notes;
- branch and tag names.

This overrides older plans and specs in `docs/` that ask for Russian commit messages.

Code comments, tests and documents under `docs/` keep the language of the surrounding text.
