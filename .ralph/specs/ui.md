# Spec: UI (Ink TUI)

## Макет

```
┌───────────────────────────┬──────────────────────────────────────────┐
│ SESSIONS                  │                                          │
│ > fix parser bug   12м ⚡O │                                          │
│   harness handoff  1ч 4м  │   Правая панель:                         │
│   refactor tui     33м    │   v0 — плейсхолдер (подсказка клавиш)    │
│   ...                     │   v1 — встроенный PTY с настоящим        │
├───────────────────────────┤        `claude` (см. specs/pty.md)       │
│ SUBSESSIONS               │                                          │
│ ▸ explore codebase  [Opus]│                                          │
│ ▸ run tests       [Sonnet]│                                          │
└───────────────────────────┴──────────────────────────────────────────┘
```

- Слева сверху — список сессий: имя (summary), относительное время, длительность,
  бейдж primaryModel; сортировка по свежести (endedAt desc).
- Слева снизу — подсессии выбранной сессии: task (первая реплика), бейджи моделей,
  длительность.
- Справа — v0: плейсхолдер; v1+: PTY.
- Ширина левой колонки ~35-40%, минимум 30 колонок; правая — остальное.

## Клавиатура

- `↑/↓` или `j/k` — навигация по активному списку
- `Tab` — переключение панелей (sessions → subsessions → [terminal] → sessions)
- `Enter` (v1+) — открыть `claude --resume <id>` справа
- `r` — принудительный ре-скан
- `q` / `Ctrl+C` — выход (в v1 — только когда фокус НЕ на терминале)
- Активная панель подсвечена рамкой/заголовком.

## Рендеринг

- Стоковый Ink, НИКАКОГО кастомного рендерера. Обоснование (из хендоффа): тяжёлая
  инженерия рендеринга Claude Code существует ради 60fps-стриминга, которого здесь
  нет — перерисовки событийные (watcher, раз в секунды).
- Данные приходят из @harnas/core (typed API поверх того же кода, что CLI).
- Длинные списки — виртуализация окном (рендерить только видимые строки).

## Перф

- Не измерялся — задача v0. План: замерить startup на самом большом реальном файле.
- Если медленно: лениво — при старте только индекс (мета), полное дерево при выборе
  сессии; кэш распарсенного по mtime файла.

## Smoke-чеклист (ручной, для финальной задачи)

1. Запуск в пустом `~/.claude/projects` — внятное пустое состояние, не краш.
2. Запуск на реальных данных — список совпадает с `claude-export/index.json`.
3. Новая сессия Claude Code в соседнем терминале появляется в списке без рестарта.
4. Выбор сессии показывает её подсессии с бейджами моделей.
5. Ресайз терминала не ломает макет.
